# roulette-3d

구슬을 떨어뜨려 당첨자를 뽑는 추첨 게임의 3D 버전입니다.

[Marble Roulette by lazygyu](https://github.com/lazygyu/roulette) 의 소스 코드를 기반으로 하며, 원본의 2D 캔버스 렌더링을 3D 로 바꾸는 리팩터링 프로젝트입니다. 원작자와는 관련이 없는 개인 프로젝트입니다.

## 현재 상태

원본에서 되던 플레이가 모두 3D 화면에서 동작하고, 그림자·발광·결승 연출 같은 3D 비주얼이 들어가 있습니다. 지금부터는 원본과 같은 기능을 유지하는 대신 3D 전용 추첨 게임으로 다시 짜는 중입니다(스킬·녹화·2D 화면 등을 걷어내고, HTML HUD 와 로비 → 맵 선택 → 게임 → 결과 화면 흐름을 만듭니다). 계획과 진행 상황은 [docs/roadmap.md](docs/roadmap.md) 를 참고해 주세요. 주소에 `?renderer=2d` 를 붙이면 원본과 같은 2D 화면으로 볼 수 있습니다.

## 실행

```shell
pnpm install
pnpm dev
```

개발 서버는 http://localhost:1236 에서 열립니다.

설정의 맵 선택 옆 `+` 버튼으로 맵 파일(JSON) 을 불러올 수 있습니다. 원본과 같은 맵 형식을 씁니다.

```shell
pnpm build      # 프로덕션 빌드
pnpm test       # 테스트
pnpm lint       # 린트와 포맷
```

## 접근 방식

물리 시뮬레이션은 원본과 같은 2D(Box2D) 를 그대로 쓰고, 화면 표현만 3D 로 바꾸는 2.5D 방식입니다.

- 원본의 맵 데이터를 수정 없이 그대로 사용할 수 있습니다.
- 물리를 건드리지 않으므로 같은 조건에서 물리 시뮬레이션 결과가 원본과 같습니다.
- 순위 계산, 카메라 추적, 슬로모션 연출 로직을 재사용합니다.
